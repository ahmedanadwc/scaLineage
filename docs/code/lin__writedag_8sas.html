Detailed Description

Writes up to three files into p_outDir (render them with Graphviz, e.g. dot -Tsvg x.dot -o x.svg):

  • <p_name>_dataset.dot data set level DAG: files, data sets and steps (data sets are cylinders, no columns); with p_attrs_yn=Y it links to <p_name>_dataset_attrs.svg
  • <p_name>_dataset_attrs.dot (only when p_attrs_yn=Y) the same DAG with the columns listed inside the data set nodes; links to <p_name>_column.svg when the column DAG is written
  • <p_name>_column.dot column level DAG: one box per column, grouped in a cluster per data set, one arrow per lineage edge (colour = how the column was derived)

Colours in the column DAG: grey = same name (NAME), blue = expression (EXPR), purple = rename, green = read from a file, red outline = unresolved (the step has source, but it does not say where the column came from), orange outline = the step has no recorded source (NOSOURCE). A data set written more than once appears once per version, e.g. WORK.ONE (v2).

Needs the tables of lin_readLog and lin_buildLineage. Example usage: 

%lin_writeDag(p_prefix=lin
, p_outDir=
, p_name=
, p_attrs_yn=Y
, p_includeSteps_yn=Y
, p_columnDag_yn=Y
, p_rankDir=LR
, p_stepsDsName=work.&p_prefix._steps
, p_dsioDsName=work.&p_prefix._dsio
, p_fileioDsName=work.&p_prefix._fileio
, p_attrsDsName=work.&p_prefix._attrs
, p_srcDsName=work.&p_prefix._src
, p_dsverDsName=work.&p_prefix._dsver
, p_cmemDsName=work.&p_prefix._cmem
, p_collinDsName=work.&p_prefix._collin)
Parameters
[in]p_prefix=Prefix of the WORK tables. Default:lin.
[in]p_outDir=Output folder. Required.
[in]p_name=Base name of the output files. Required.
[in]p_attrs_yn=Y|N also write <p_name>_dataset_attrs.dot, the dataset DAG with the columns listed. Default:N.
[in]p_includeSteps_yn=Y|N draw the processing steps (with run time) in the dataset DAG. Default:Y.
[in]p_columnDag_yn=Y|N also write the column DAG. Default:Y.
[in]p_rankDir=TB|BT|LR|RL layout direction. Default:LR.
[in]p_stepsDsName=Stepinformation for each step. Default: work.&p_prefix._steps
[in]p_dsioDsName=Datasetinput/output information for each step. Default: work.&p_prefix._dsio
[in]p_fileioDsName=Fileinput/output information for each step. Default: work.&p_prefix._fileio
[in]p_attrsDsName=Attributeinformation for each step. Default: work.&p_prefix._attrs
[in]p_srcDsName=Sourcecode for each step. Default: work.&p_prefix._src
[in]p_cmemDsName=Columnmemory information for each step. Default: work.&p_prefix._cmem
[in]p_collinDsName=Columnlineage information for each step. Default: work.&p_prefix._collin
[in]p_dsverDsName=Datasetversion information for each step. Default: work.&p_prefix._dsver
