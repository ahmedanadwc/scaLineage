scaLineage
Custom built SAS macro programs to trigger recording and extracting information about input, output, and the use of macro symbols from a SAS program while it is running. The captured information can provide a simple static data lineage diagram. As a minimum, Base SAS Software, version 9.4 Maintenance 4 installation is required to run these macros.

1/**
2 @file lin_processlog.sas
3 @brief Extracts the data / column lineage of ONE SCAPROC recording and draws its DAGs.
4 @details Runs the whole chain for one *.txt file:
5 %lin_readLog -> %lin_prepSource -> %lin_exprDataStep + %lin_exprSql -> %lin_tokenize -> %lin_buildLineage -> %lin_writeDag
6
7 and writes into p_outDir
8 |Name|Description|
9 |---|---|
10 |<p_name>_dataset.dot|data set level DAG|
11 |<p_name>_column.dot|column level DAG|
12 |<p_name>_column_lineage.csv|one row per column lineage edge (see %lin_buildLineage)|
13 |<p_name>_dataset_lineage.csv|one row per step input / output (data sets and files, with version)|
14 |<p_name>_steps.csv|one row per step (proc, elapsed, duration)|
15 |<p_name>.json|node / edge graph of both levels (only when p_json_yn=Y)|
16 |<p_name>_source.csv|one row per source|
17
18
19A one-row summary is appended to WORK.LIN_SUMMARY (created on first use).
20The global macro variable G_LINRC is 0 when the log was processed, otherwise
211 = p_inFile / p_outDir missing, 2 = input does not exist, 3 = output folder does not exist,
224 = the file holds no SCAPROC steps.
23
24 Example usage:
25
26 %lin_processLog(p_inFile=%str(~/logs/sca__fuzzy.txt), p_outDir=%str(~/lineage/fuzzy), p_attrs_yn=Y)
27
28 @param [in] p_inFile= SCAPROC text file. Required.
29 @param [in] p_outDir= Existing output folder. Required.
30 @param [in] p_name= Base name of the output files. Default: the file name without its extension.
31 @param [in] p_attrs_yn= Y|N list the columns inside the data set nodes of the dataset DAG. Default:N.
32 @param [in] p_includeSteps_yn= Y|N draw the processing steps in the dataset DAG. Default:Y.
33 @param [in] p_columnDag_yn= Y|N also write the column DAG. Default:Y.
34 @param [in] p_rankDir= TB|BT|LR|RL layout direction. Default:LR.
35 @param [in] p_json_yn= Y|N also write <p_name>.json (nodes / edges of both levels, see %lin_writeJson). Default:N.
36 @param [in] p_prefix= Prefix of the WORK tables used while processing. Default:lin.

161 PROC SQL;
162 CREATE TABLE work._lin_dslin AS
163 SELECT d.step, s.procname, d.io
164 , 'DATASET' AS kind LENGTH=8
165 , d.ds AS name LENGTH=1000
166 , d.ver
167 FROM &p_prefix._dsver d
168 LEFT JOIN &p_prefix._steps s ON s.step=d.step
169 UNION
170 SELECT f.step,
171 s.procname, CASE f.role WHEN 'INPUT' THEN 'IN' ELSE 'OUT' END, 'FILE',
172 f.path, .
173 FROM &p_prefix._fileio f
174 LEFT JOIN &p_prefix._steps s ON s.step=f.step
175 ORDER BY 1, 3, 5;
176 QUIT;
