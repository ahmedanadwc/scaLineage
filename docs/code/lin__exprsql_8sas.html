Extracts column derivations from the recorded source of PROC SQL steps. More...

Detailed Description

Understands CREATE TABLE|VIEW x AS SELECT ... and INSERT INTO x SELECT ..., including joins, table aliases, CASE expressions, calculated columns and UNION / INTERSECT / EXCEPT. Creates

  • work.&p_prefix._exprSql: Column derivations from the recorded source of PROC SQL steps

    Variable Description
    step The step number of the SQL step
    qid The query ID (one per SELECT segment)
    toRaw The raw text of the target (output) column
    toVar The name of the target (output) column
    pos The position of the column in the output
    kind The kind of derivation (always EXPR)
    expr The expression that defines the column

  • work.&p_prefix._alias: Concatenated Library alias information
    Variable Description
    step The step number of the SQL step
    qid The query ID (one per SELECT segment)
    alias The alias of the table
    tblRaw The raw text of the table

Example usage: 

%lin_exprSql(p_prefix=&p_prefix, p_stmtsDsName=work.&p_prefix._stmts
, p_stepsDsName=work.&p_prefix._steps)

qid numbers the query segments of a step (a UNION has one qid per SELECT). Select items of the second and later segments take the column name of the item at the same position in the first segment. SELECT * / a.* items produce no row: they are covered by matching the column names.

Note
Not handled: nested sub-queries in the FROM clause are treated as unknown tables (the columns are then matched by name against every input table).
Parameters
[in]p_prefix=Prefix of the WORK tables. Default:lin.
[in]p_stmtsDsName=Sourcecode for each step. Default: work.&p_prefix._stmts
[in]p_stepsDsName=Stepinformation for each step. Default: work.&p_prefix._steps
