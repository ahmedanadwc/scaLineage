lin_readlog.sas File Reference

Reads ONE SCAPROC (SAS Code Analyzer) recording into tidy lineage tables. More...

Go to the source code of this file.

Detailed Description

Every record in the recording starts with the text /* JOBSPLIT: . The step number is advanced on each TASKSTARTTIME record, so every table below can be joined on STEP.

Creates (all in WORK, named with the p_prefix):

  • work.&p_prefix._steps: Step information for each step

    variable Description
    step The step number of the step
    procname The name of the procedure
    elapsed The elapsed time of the step
    startDt The start date and time of the step
    durSec The duration of the step in seconds

  • work.&p_prefix._dsio: Dataset input/output information for each step

    variable Description
    step The step number of the step
    role The role of the dataset (INPUT, OUTPUT, UPDATE)
    ds The dataset name (LIB.MEM, upper case)
    memtype The type of the dataset (DATA, VIEW)

  • work.&p_prefix._fileio: File input/output information for each step

    variable Description
    step The step number of the step
    role The role of the file (INPUT, OUTPUT)
    path The path of the file

  • work.&p_prefix._attrs: Attribute information for each step

    variable Description
    step The step number of the step
    ord The record order
    role The role of the attribute (INPUT, OUTPUT)
    ds The dataset name (LIB.MEM, upper case)
    var The variable name
    type The type of the variable
    length The length of the variable
    label The label of the variable
    format The format of the variable
    informat The informat of the variable

  • work.&p_prefix._src: Source code for each step

    variable Description
    step The step number of the step
    lineno The line number of the source code
    text The text of the source code

  • work.&p_prefix._cmem: Concatenated Library alias information
    variable Description
    alias The alias of the library
    rlib The real library name

Utility files (WORK.'SASTMP-...'.UTILITY, written by PROC SORT) are ignored. SAS opens concatenated libraries such as SASHELP under an internal alias (libref #C00003, announced by a CONCATMEM record); the alias is replaced by the real library (SASHELP.PRDSALE). An alias without a CONCATMEM record is dropped.

Example usage: 

%lin_readLog(p_inFile=%str(<Path>/<FileName>.txt), p_prefix=lin)
Parameters
[in]p_inFile=Full path of the SCAPROC text file. Required.
[in]p_prefix=Prefix of the WORK tables created. Default:lin.
