lin_runall.sas File Reference

Extracts lineage and draws the DAGs for EVERY SCAPROC text file in a folder. More...

Go to the source code of this file.

Detailed Description

Lists p_logDir, and runs lin_processLog for each file with the extension p_ext. Every log gets its own sub-folder under p_outDir (named after the file), holding the files below

  • *_dataset.dot
  • *_dataset_attrs.dot
  • *_column.dot
  • *_steps.csv
  • *_dataset_lineage.csv
  • *_column_lineage.csv

Files that are empty or hold no SCAPROC steps are reported in the summary and skipped. The one-row-per-log summary is written to <p_outDir>/lineage_summary.csv and is left in WORK.LIN_SUMMARY.

Example usage: 

%lin_runAll(p_logDir=%str(<Path>/logs)
, p_outDir=%str(<Path>/lineage)
, p_attrs_yn=Y)
Parameters
[in]p_logDir=Folder holding the SCAPROC text files. Required.
[in]p_outDir=Existing output folder. Required.
[in]p_ext=Extension of the files to process. Default:txt.
[in]p_attrs_yn=Y|N list the columns inside the data set nodes of the dataset DAG. Default:N.
[in]p_includeSteps_yn=Y|N draw the processing steps in the dataset DAG. Default:Y.
[in]p_columnDag_yn=Y|N also write the column DAG. Default:Y.
[in]p_rankDir=TB|BT|LR|RL layout direction. Default:LR.
[in]p_json_yn=Y|N also write a .json graph per recording. Default:N.
