lin_writejson.sas File Reference

Writes the lineage of one SCAPROC recording as a node / edge JSON graph. More...

Go to the source code of this file.

Detailed Description

One file holds both levels, so a consumer can filter on "level":

  • nodes {"id", "label", "type", "level", ...}
    type "dataset" (level dataset; "columns": [{name, type}] when p_attrs_yn=Y), "file", "step" (with "step" number), "column" (level column; "dataset" = id of its data set node, "unresolved": true when the step has source that does not say where the column came from, "nosource": true when the step has no recorded source)

  • edges {"source", "target", "type", "level", ...}
    level dataset: type "input" (to a step), "output" (from a step) or "flow" (no step nodes)
    level column: type "column", "method" (EXPR|RENAME|NAME|FILE|INPUT|CONST), "step", "expr"
Note
Node ids are the ids used in the DOT files. A data set written more than once is one node per version.

Needs the tables of lin_readLog and lin_buildLineage.

Parameters
[in]p_prefix=Prefix of the WORK tables. Default:lin.
[in]p_outFile=Full path of the JSON file. Required.
[in]p_name=Name stored in the "source" field. Required.
[in]p_attrs_yn=Y|N list the columns inside the data set nodes. Default:N.
[in]p_includeSteps_yn=Y|N step nodes with input -> step -> output edges. Default:Y.
[in]p_columnGraph_yn=Y|N include the column nodes and column edges. Default:Y.
[in]p_stepsDsName=Stepinformation for each step. Default: work.&p_prefix._steps
[in]p_fileioDsName=Fileinput/output information for each step. Default: work.&p_prefix._fileio
[in]p_attrsDsName=Attributeinformation for each step. Default: work.&p_prefix._attrs
[in]p_collinDsName=Columnlineage information for each step. Default: work.&p_prefix._collin
[in]p_dsverDsName=Datasetversion information for each step. Default: work.&p_prefix._dsver
