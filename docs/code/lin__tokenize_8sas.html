Turns the derivation expressions into column references. More...

Detailed Description

Reads work.&p_prefix._exprDs and work.&p_prefix._exprSql and creates

  • work.&p_prefix._eexpr: Expression information for each step.

    Variable Description
    eid Expression ID
    step Step number
    qid Query ID
    toRaw Target raw column
    toVar Target variable
    pos Position in the expression
    kind Type of expression
    expr Expression text
    qual Qualifier (alias or data set)
    ident Column identifier
    calc Flag indicating if the column is calculated

  • work.&p_prefix._ref: Column references for each expression.
    Variable Description
    eid Expression ID
    qual Qualifier (alias or data set)
    ident Column identifier
    calc Flag indicating if the column is calculated

An expression is the right hand side of one assignment or select item. A reference is a column name used inside it. Quoted strings, function calls (name followed by a bracket), formats (name followed by a dot), macro variables, numbers and language keywords are not references. 'alias.column' keeps the alias in QUAL, and a column that follows the SQL keyword CALCULATED has CALC=1. RENAME rows give one reference to the old name; its QUAL is the data set of the rename= option.

Example usage: 

%lin_tokenize(p_prefix=lin)
Parameters
[in]p_prefix=Prefix of the WORK tables. Default:lin.
[in]p_exprSqlDsName=Expressioninformation for each SQL step. Default: work.&p_prefix._exprSql
[in]p_exprDsDsName=Expressioninformation for each DATA step. Default: work.&p_prefix._exprDs
