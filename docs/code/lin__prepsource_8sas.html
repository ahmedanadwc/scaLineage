Splits the recorded source of every step into statements. More...

Detailed Description

Reads &p_prefix._src (see lin_readLog) and creates

  • work.&p_prefix._stmts: Source code for each step split into individual statements
    Variable Description
    step The step number of the statement
    stmtno The statement number within the step
    text The text of the statement (no trailing semicolon)

Example usage: 

%lin_prepSource(p_prefix=&p_prefix, p_srcDsName=work.&p_prefix._src)

Cleaning applied before splitting: block comments are removed, in-stream data (DATALINES/CARDS ... ;) is dropped, white space is collapsed, and semicolons inside quoted strings do not end a statement.

Steps generated by a macro have no recorded source; they simply get no rows here, and the lineage engines fall back to matching columns by name.

Parameters
[in]p_prefix=Prefix of the WORK tables. Default:lin.
[in]p_srcDsName=Source code for each step. Default: work.&p_prefix._src
